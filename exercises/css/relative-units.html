Omvandla rem till px för ett <p> i koden nedan?

html {
  font-size: 4px;
}

p {
  font-size: 3rem;
}

Korrekt!

Inte riktigt...

4px * 3 = 12px

Tänk på att rem beräknas relativt till font-size som anges för <html>-elementet.

Vad är border-radius i px på ett <button> i koden nedan?

<div class="largeContainer"></div>
<div class="container">
  <p class="description"></p>
  <button></button>
</div>

html {
  font-size: 20px;
}

.largeContainer {
  font-size: 1.5rem;
}

.container {
  border-radius: 0.5rem;
}

.description {
  font-size: 0.8em;
}

.container button {
  font-size: 1.5rem;
  border-radius: 0.5em;
}

Korrekt!

Inte riktigt...

Eftersom <button> har font-size som är lika med 1rem = 1.5 * 20px = 30px, kommer border-radius att vara 0.5 * 30px = 15px.

Börja med att ta reda på knappens font-size och sedan multiplicera det med hur många em som anges för border-radius.
