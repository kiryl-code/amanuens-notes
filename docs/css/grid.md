# Grid

!!!!warning
***UTVECKLING PÅGÅR***

Se "utveckling pågår" i menyn till vänster för mer information.
!!!!

Grid är en ytterligare modern teknik som används för att positionera element på sidan. Precis som det låter använder grid ett rutnät och placerar elementerna i "celler" i rutnätet.

Precis som med flexbox behöver vi göra en behållare till en grid-behållare. Vi gör det direkt i startkoden.

^^^^Grid, startkod
```html
<body>
    <header></header>
    <aside></aside>
    <main></main>
    <footer></footer>
</body>
```

```css
body {
    display: grid;
}

header {
    
}

aside {
    
}

main {
    
}

footer {
    
}
```
