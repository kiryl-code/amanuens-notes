# Cascading Style Sheets

Precis som HTML är CSS inte ett programmeringsspråk. CSS används för att beskriva utseendet på olika HTML-element. CSS körs direkt i webbläsaren som tolkar stilarna och tillämpar dem. CSS-koden kan skrivas i HTML eller i separata filer med filändelsen `.css`. Den absolut största delen av CSS-koden fungerar på samma sätt i de flesta populära webbläsare. Vissa webbläsare implementerar dock egna regler som kanske inte stöds av andra webbläsare. Oftast handlar detta om väldigt nischade regler och du kommer troligtvis inte att stöta på dem. Till skillnad från HTML har CSS ingen specifik version, utan versionsnumreringen stannade på CSS3. Sedan dess har många nya funktioner lagts till, men eftersom tekniken alltid utvecklas och nya regler (inklusive webbläsarspecifika regler) införs används inte versionsnummer i CSS.
