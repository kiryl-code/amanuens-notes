# Hyper Text Markup Language

HTML är _inte_ ett programmeringsspråk, utan är ett så kallad _markup language_. Detta är eftersom det först och främst används för att deklarera de element som ska visas på en webbsida, men kan sällan styra elementens beteende (med några undantag) och ger ingen möjlighet för en riktig programmering med variabler, flödeskontroll och liknande. Språket används alltså för att skapa strukturen på en webbsidans innehåll. HTML körs direkt i webbläsare som tolkar koden och visar innehållet, vilket betyder att du inte behöver installera några särskilda program för att köra HTML koden. Det räcker med en valfri webbläsare (chromium- eller firefox-baserade rekommenderas). HTML koden skrivs i filer med `.html` filändelse och man kan använda precis vilken som helst textredigerare för att skriva HTML kod. Jag rekommenderar att du använder *WebStorm* eller *Visual Studio Code* för att få syntax highlight och för att få med ytterligare några hjälpsamma funktioner.

Den sista versionen av HTML är **HTML5** som är standard för modern webbutveckling. Vidare när jag pratar om HTML (även om jag inte nämner någon version explicit) menar jag alltid just HTML5.
