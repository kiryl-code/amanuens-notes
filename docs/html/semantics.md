# Semantik

När det kommer till webbsidor och HTML5 vill vi alltid göra webbsidor så tillgängliga som möjligt. Detta innebär bland annat korrekt användning av taggar så att lämpliga element används för innehållet. Till exempel ska vi placera en navigationsmeny i `<nav>`, information längst ner på sidan i `<footer>` och så vidare. Dessa element kallas **semantiska**, det vill säga självförklarande. De vanligaste elementen som du kommer att jobba med är:

- `<header>` - representerar sidans huvud och introduktionsinnehåll och innehåller ofta titel, beskrivning, bakgrundsbild och navigationsmeny. Kan även användas för att skapa en sidhuvuddel i olika avsnitt på sidan.
- `<nav>` - navigationsmeny.
- `<main>` - sidans huvudsakliga, unika innehåll. Det får endast finnas ett `<main>`-element.
- `<section>` - ett avsnitt som normalt bör ha en rubrik, exempelvis från `<h2>` till `<h6>`.
- `<article>` - fristående, självständigt innehåll, exempelvis ett blogginlägg eller en artikel. Det här elementet representerar innehåll som skulle kunna distribueras helt separat.
- `<aside>` - representerar innehåll som har ett indirekt förhållande till sidan, till exempel en faktaruta eller reklam.
- `<footer>` - ett element som placeras längst ner på sidan eller i slutet av ett avsnitt och innehåller exempelvis copyrightinformation, länkar till sociala medier och så vidare.

Dessa element har ingen direkt påverkan på utseendet, men är viktiga för skärmläsare, sökmotorer och andra tekniker inom både tillgänglighet och SEO (*Search Engine Optimization*, sökmotoroptimering).
